**Rule: never let more than two agents share one model, and put the
heaviest tasks on `kilo-key` first.**

**`kilo-key` has a 600-SECOND PER-REQUEST CAP** ("the response reached the
gateway's 600-second duration limit and was stopped before it finished"). A
kilo-key agent doing a big implementation task WILL be cut off mid-work with
nothing on disk. So: **kilo-key is for SHORT, self-contained tasks
(probing, reporting, writing a document); put the long implementation
tracks on cline-key**, and tell every agent to **work in increments and
save to disk as it goes** — a track that exists only in a subagent's context
is a track that dies with it.

**Other provider behaviours observed:** 404 "model not found" = the id
vanished from the provider's list (respawn with a different model); 429
"Daily limit reached ... Credits don't affect this cap" = that model is done
for the day; 429 "temporarily rate-limited upstream ... route to another
provider" = a shared upstream pool, retry later or use another provider;
"API key auth failed for provider cline-key: Failed to resolve API key from
shell command ~/.pi/agent/scripts/cline-token.sh" = transient (the script
works by hand; it is a refresh race when many agents resolve at once).

## The key numbers to beat (the bar)

- **The n-gram bar.** On the ruler's own held-out bytes, an **order-8 byte
  n-gram (0 parameters, 8 MB)** scores **0.6512** nats/byte; the model
  scores **1.2094**. The model is **0.56 nats/byte worse than a lookup
  table**. Reproducible: `tools/ngram_ce.py`.
- **The memory bar.** The payload is decodable at 4.6× its own null at
  8-12 B of lag, 1.5× at 128 B; the cue key at 65-165×.
- **The T4 bar.** 26.72 ms/step with nvrtc (was 33.68 with the inert
  default), 15 GB, 1,072 launches, tail 10.2 ms, optimizer 3.0 ms.

## Rules for this session

1. **Never trust a number without its null.** Every cell carries a matched
   null, a nuisance control, and a class-coverage figure.
2. **A bit-identical change is free; a re-association is not.** Measure
   `max|Δ|` and the loss before adopting any optimisation.
3. **A null with a measured cause is a result.** An instrument bug is a bug.
4. **One ssh at a time per machine.**
5. **Respawn on provider errors.** Do not stall.
