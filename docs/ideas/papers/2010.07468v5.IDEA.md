# Paper notes — "AdaBelief Optimizer" (arXiv:2010.07468v5)

**Paper:** Juntang Zhuang, Tommy Tang, Yifan Ding, Sekhar Tatikonda, Nicha Dvornek,
Xenophon Papademetris, James S. Duncan — *AdaBelief Optimizer: Adapting Stepsizes by
the Belief in Observed Gradients*, arXiv:2010.07468v5, **NeurIPS 2020**.

**Source text:** `2010.07468v5.paper.txt`; `2010.07468v5.paper.html.gz`.

**Verification status: VERIFIED — the mechanism claim is exactly right.**
Abstract page fetched 2026-10-05. The attributed claim — *"second moment uses
(g−m)², so the denominator is a consistency measure"* — is confirmed verbatim in
§2 and the algorithm box: "in Adam, the update direction is `m_t/√v_t`, where `v_t`
is the EMA of `g_t²`; in AdaBelief, the update direction is `m_t/√s_t`, where `s_t`
is the EMA of `(g_t − m_t)²`. Intuitively, viewing `m_t` as the **prediction** of
`g_t`, AdaBelief takes a large step when observation `g_t` is close to prediction
`m_t`, and a small step when the observation greatly deviates from the prediction."
No extra parameters are introduced (Adam's `v_t` is simply replaced by `s_t`).
One detail the external gloss omitted: an extra `ε` is added to `s_t` during bias
correction so that `s_t` is bounded below.

**Status of this note:** external ideas, not a plan and not a result.

---

## 1. Why this is the most structurally interesting item for TMT

AdaBelief's denominator is **not** a scale estimate. It is a **prediction-error
estimate**: how surprising this byte's gradient was, given the momentum prediction.
That is a *different observable* from Adam's second moment, and it is the first
entry on this shelf whose value is not a monotone function of gradient magnitude.

The TMT measurement this reframes — from `RESULTS.md`, under the retracted-claims
section: *"Adam does not degenerate to `sign(m)` — it is normalized SGD with a
constant normalizer (`|update|/|m|` spread 1.0020×, `|m|` spread 763×)"* — is
exactly a finding about a *constant normalizer*. If Adam's denominator is constant
across coordinates, then Adam carries **no per-coordinate information at all** and
AdaBelief's `s_t` would carry *some*. That makes AdaBelief a direct, cheap test of
whether the repo's "Adam's second moment is non-discriminating" claim is a property
of Adam or a property of TMT's gradients.

Named test: log both `v_t` (Adam) and `s_t` (AdaBelief) on the same run, same seed,
same data order; report the per-coordinate spread of each and the Spearman rank
correlation of each against the true per-coordinate SNR. If `s_t` has spread while
`v_t` has ~none, the "non-discriminating second moment" is an Adam artefact and
AdaBelief is the instrument that exposes the signal Adam threw away. Run the
optimiser arm at matched `--lr` and at Smith et al.'s `B ∝ ε` setting before
concluding anything.

## 2. What this paper does NOT support

- It does **not** say AdaBelief generalises better because it is "consistent." The
  generalisation claim is empirical, on CNNs (CIFAR, ImageNet), one language model,
  and a W-GAN. §2.2 offers two hand-drawn 1-D cases (Table 1) in which AdaBelief
  matches "an ideal optimizer" — an illustration, not evidence.
- It does **not** cover recurrent, byte-level, or long-horizon models. The paper's
  sequence model is a language model without a stated long-range memory test.
- It does **not** establish that the *consistency* interpretation is the causal
  mechanism. It is the stated intuition; no ablation removes `m_t` from the
  denominator and shows the benefit disappears.
- It does **not** address what happens when `s_t` is itself noise-dominated — which
  is TMT's actual regime. If every byte's gradient is unpredictable, `s_t` is large
  everywhere and AdaBelief becomes uniform-step SGD.
- No `ε` handling, bias-correction, or interaction with weight decay is analysed
  for TMT's 8,192 dedicated `.decay` coordinates (8,192 of 4,481,793 = 0.183 %).

## 3. Bearing on the three open questions

- **Noise floor vs over-large step?** AdaBelief is *diagnostic-first*: if `s_t` is
  large and uniform, the gradients are genuinely unpredictable at this step size →
  noise-floor evidence. If `s_t` discriminates, the gradients carry structure that
  Adam's denominator threw away → over-large-step evidence. This is the cheapest
  discriminator on the whole shelf.
- **Estimator vs optimiser?** Explicitly optimiser. No change to the gradient
  estimator; only `v_t → s_t`.
- **Input-dependent gating?** No bearing. (AdaBelief's own answer is that a
  *prediction-error-gated* step suffices — which is weak evidence *against* needing
  input-dependent architectural gating, since the gating that helps is in the
  optimiser, not the model.)
